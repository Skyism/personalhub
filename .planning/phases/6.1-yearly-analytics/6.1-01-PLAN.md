<objective>
Add yearly analytics data layer and page foundation: aggregate transactions by year, show total spent and per-category breakdown (including Uncategorized), with year selector and summary.

Purpose: Enable viewing annual spending statistics and category breakdown for a selected year.
Output: Route /finance/analytics/yearly with year selector, total spent, transaction count, and category breakdown table. No new tables; read-only aggregation from transactions + categories.
</objective>

**Data:**
- transactions: user_id, budget_id, category_id, amount, transaction_date
- categories: id, user_id, name, color
- Filter: transaction_date >= Y-01-01 and transaction_date < (Y+1)-01-01
- Total: SUM(amount). Per-category: GROUP BY category_id (null → "Uncategorized")

**Patterns:** Server Component data fetch, TEMP_USER_ID, TopAppBar, Link back to analytics

  <action>
Create Server Component at `app/finance/analytics/yearly/page.tsx`:

1. **Search params:** Accept `year` (default: current year, or latest year that has any transaction for user).

2. **Queries:**
   - Fetch all transactions for TEMP_USER_ID (no budget filter). Filter in code by transaction_date in [year-01-01, year-12-31] (use date part; timezone-safe).
   - Fetch all categories for user (for names/colors).
   - Optionally: single query for transactions in year range, or fetch and filter. Prefer one query with .gte('transaction_date', `${year}-01-01`).lte('transaction_date', `${year}-12-31`) if Supabase supports; else fetch and filter in JS.

3. **Aggregations:**
   - totalSpent: sum of amount for filtered transactions.
   - transactionCount: filtered length.
   - categoryBreakdown: array of { categoryId: number | null, name: string, amount: number, color: string | null }. Group by category_id; null → name "Uncategorized", color null. Join with categories for name/color where category_id not null. Sort by amount descending.

4. **Available years:** From same transactions table, get distinct years (extract from transaction_date). Use for year selector options (dropdown). Default selected year = searchParam year or current year if it has data, else latest year with data.

5. **Layout:** TopAppBar fallbackHref="/finance/analytics". Title "Yearly Spending". Year selector (dropdown, navigates to ?year=YYYY). Summary card: "Total spent: $X" and "N transactions". Table: Category name | Amount (formatted currency). Use card/table styling consistent with rest of Finance (bg-card, rounded-lg, border).

6. **Empty state:** If no transactions in selected year, show "No transactions in {year}" and hide table. Still show year selector.
