  <name>Task 1: Create trip server actions</name>
  <files>app/finance/wants/trips/actions.ts</files>
  <action>
Create server actions file with the following functions:

**Trip CRUD:**
- createTrip(name, destination, startDate, endDate, budgetAmount, wantsBudgetId) - Insert into wants_trips with status 'planned'
- updateTrip(tripId, name, destination, startDate, endDate, budgetAmount) - Update trip details
- activateTrip(tripId) - Set status to 'active' (DB constraint ensures only one active)
- completeTrip(tripId) - Set status to 'completed'
- deleteTrip(tripId) - Delete trip (CASCADE removes transactions)

**Trip Transaction CRUD:**
- createTripTransaction(tripId, wantsBudgetId, amount, note, transactionDate) - Insert with source 'manual'
- updateTripTransaction(transactionId, amount, note, transactionDate) - Update transaction
- deleteTripTransaction(transactionId) - Delete transaction

All actions use TEMP_USER_ID, revalidatePath('/finance/wants/trips'), and follow the pattern in app/finance/wants/actions.ts.
  </action>
