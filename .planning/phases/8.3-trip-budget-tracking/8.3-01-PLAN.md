Create database migration for trip budget tracking with two tables:

**Table 1: wants_trips**
- id: bigint PRIMARY KEY GENERATED ALWAYS AS IDENTITY
- user_id: uuid NOT NULL
- wants_budget_id: bigint NOT NULL REFERENCES wants_budgets(id) ON DELETE CASCADE
- name: text NOT NULL (trip name, e.g., "Japan 2026")
- destination: text (optional destination)
- start_date: date NOT NULL
- end_date: date NOT NULL
- budget_amount: numeric(10,2) NOT NULL CHECK (budget_amount > 0)
- status: text NOT NULL DEFAULT 'planned' CHECK (status IN ('planned', 'active', 'completed'))
- created_at: timestamptz DEFAULT now()
- updated_at: timestamptz DEFAULT now()
- Index on user_id
- Index on (user_id, status) for active trip lookup
- Partial unique index: CREATE UNIQUE INDEX idx_wants_trips_one_active ON wants_trips(user_id) WHERE status = 'active' — enforces at most one active trip per user

**Table 2: wants_trip_transactions**
- id: bigint PRIMARY KEY GENERATED ALWAYS AS IDENTITY
- user_id: uuid NOT NULL
- trip_id: bigint NOT NULL REFERENCES wants_trips(id) ON DELETE CASCADE
- wants_budget_id: bigint NOT NULL REFERENCES wants_budgets(id) ON DELETE CASCADE
- amount: numeric(10,2) NOT NULL
- note: text
- transaction_date: date DEFAULT CURRENT_DATE
- source: text NOT NULL DEFAULT 'manual' CHECK (source IN ('manual', 'sms'))
- twilio_message_id: text UNIQUE (for SMS idempotency, nullable)
- created_at: timestamptz DEFAULT now()
- updated_at: timestamptz DEFAULT now()
- Index on (user_id, trip_id)
- Index on (user_id, wants_budget_id) for dual-deduction aggregation
- Index on transaction_date
- Index on twilio_message_id (WHERE twilio_message_id IS NOT NULL)

Enable Row Level Security on both tables. Create RLS policies:
- wants_trips: SELECT/INSERT/UPDATE/DELETE where user_id = TEMP_USER_ID
- wants_trip_transactions: SELECT/INSERT/UPDATE/DELETE where user_id = TEMP_USER_ID

Apply migration via Supabase MCP tool: mcp_supabase_apply_migration with name "create_wants_trips_schema" and SQL query.

After migration, regenerate TypeScript types via mcp_supabase_generate_typescript_types and update lib/database.types.ts.

Avoid adding computed columns or triggers. Avoid using tsrange types. Use CASCADE for referential integrity on foreign keys.
