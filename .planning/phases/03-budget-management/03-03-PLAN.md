# Phase 3 Plan 3: Budget Allocation Editing

**Add inline editing functionality for budget allocation amounts with validation**

## Goal

Enable users to edit existing budget allocation amounts directly in the budget detail page without removing and re-adding allocations.

## Background

Currently, the CategoryAllocation component supports:
- Adding new category allocations
- Removing existing allocations
- Viewing allocation amounts

**Missing:** Ability to edit allocation amounts after creation. Users must remove and re-add to change amounts.

## Tasks

### Task 1: Add updateAllocation Server Action

**File:** `app/finance/budgets/category-allocations/actions.ts`

Add new Server Action to update allocation amount:

```typescript
'use server'

export async function updateAllocation(
  budgetId: number,
  categoryId: number,
  newAmount: number
): Promise<{ success: boolean; error?: string }> {
  // 1. Validate newAmount > 0
  if (newAmount <= 0) {
    return { success: false, error: 'Please enter a valid amount' }
  }

  const supabase = await createClient()

  // 2. Get budget total
  const { data: budget } = await supabase
    .from('budgets')
    .select('total_budget')
    .eq('id', budgetId)
    .single()

  if (!budget) {
    return { success: false, error: 'Budget not found' }
  }

  // 3. Get existing allocations (excluding current category)
  const { data: existingAllocations } = await supabase
    .from('category_allocations')
    .select('allocated_amount')
    .eq('budget_id', budgetId)
    .neq('category_id', categoryId)

  const totalOtherAllocations = (existingAllocations || [])
    .reduce((sum, a) => sum + a.allocated_amount, 0)

  // 4. Validate total doesn't exceed budget
  if (totalOtherAllocations + newAmount > budget.total_budget) {
    return { 
      success: false, 
      error: 'Total allocations would exceed budget' 
    }
  }

  // 5. Update allocation
  const { error } = await supabase
    .from('category_allocations')
    .update({ allocated_amount: newAmount })
    .eq('budget_id', budgetId)
    .eq('category_id', categoryId)

  if (error) {
    return { success: false, error: error.message }
  }

  revalidatePath('/finance/budgets/[id]')
  return { success: true }
}
```

**Validation rules:**
- Amount must be > 0
- Total allocations (including new amount) must not exceed budget.total_budget
- Budget and allocation must exist

3. **Add handleSaveEdit function:**

```typescript
const handleSaveEdit = async (categoryId: number) => {
  setEditError('')

  const amountNum = parseFloat(editAmount)
  if (isNaN(amountNum) || amountNum <= 0) {
    setEditError('Please enter a valid amount')
    return
  }

  const result = await updateAllocation(budgetId, categoryId, amountNum)
  if (result.success) {
    setEditingId(null)
    setEditAmount('')
  } else {
    setEditError(result.error || 'Failed to update allocation')
  }
}
```

## Technical Approach

**Pattern:** Inline edit mode (no modal)
- Click "Edit" → input field replaces amount display
- Save/Cancel buttons replace Edit/Remove buttons
- Error messages display inline below the item
- Follows established pattern from NightMessageItem.tsx

**Validation:**
- Client-side: Check amount > 0 before calling Server Action
- Server-side: Validate total allocations don't exceed budget
- Display errors inline without alerts

**State management:**
- Track editing state per allocation (editingId)
- Only one allocation can be edited at a time
- Cancel restores original display mode
